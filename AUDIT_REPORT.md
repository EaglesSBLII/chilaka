# Chilaka content and accuracy audit

Date: 17–18 November 2026. App version audited: 0.5.3 (commit `9fd1f32`) plus the fixes below, released as 0.5.4.

Every statement here comes from a file that was read, a command that was run or a script's output. "Reviewed" for Telugu means read item by item by an AI reviewer, not by a native speaker. Nothing was auditioned by ear.

## 1. Summary

### Inventory (what exists, read from the files)

| Thing | Count | Where |
|---|---|---|
| Pathways (tracks) | 2: speaking (sections 0–8), reading & writing (sections 1–2) | `track` field of each unit |
| Units | 80 (68 speaking, 12 reading & writing) | `app/content/units/uNN.json`, one file per unit |
| Lessons | 373 | `lessons[]` inside each unit; each lists 2–8 item ids |
| Vocabulary items (words and phrases) | 1,204 | `items[]` inside each unit, id `uNN-iNN` |
| Word breakdown entries | 3,845 | `words[]` inside each item |
| Notes (tips on cards) | 538 | `note` on an item |
| Dialogues | 64 | `dialogue` on a unit; each turn points to an item id |
| Audio clips | 2,408 (1,204 per voice) | `app/public/audio/v-female/` and `v-male/`, file name = item id + `.m4a`, plus a `manifest.json` per voice |
| Reference transcripts | 1,204 per voice | `app/src/content/reference-transcripts-*.json` |

How it links: the app loads every unit file (`app/src/content/load.ts`), checks it against a schema (`schema.ts`) and sorts by track, section, order. The transliteration is **not stored**: it is derived from the Telugu script by one function (`teluguToRoman`), so a card's transliteration cannot disagree with its script. Exercises are generated from the items, never authored. A unit unlocks when the unit before it in the same track is complete.

## 6. How to rerun

```bash
node tools/validate-content.mjs
```

Options: `--audio-deep` also measures every clip's length (macOS, about a minute); `--quiet` prints errors and the summary only; `--json out.json` writes every finding to a file. It needs Node 22.18 or newer and no extra packages. It exits with code 1 if there is any error.

What it checks: the schema of every unit; unit, lesson and item ids; lesson and dialogue links; orphan items; track, section and order gaps; Telugu character validity (vowel signs, virama, nasal marks, invisible characters, other scripts, corrupted text); that each word breakdown rebuilds its sentence; placeholder text; transliteration in notes and descriptions against the app's own; wrong choices that are also right; duplicate Telugu with different meanings; letters used in the reading track before they are taught; and, for both voices, that every clip exists, is a real audio file, is listed in the manifest and has a reference transcript.
